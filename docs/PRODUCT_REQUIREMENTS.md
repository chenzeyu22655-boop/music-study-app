# 健身记录 App 第一版产品需求文档

## 产品定位

这是一个个人使用的健身记录工具，用来按日期记录身体数据、训练、饮食、身材照片，并通过 AI 分析当天状态和给出后续建议。

## 第一版核心功能

1. 按日期查看记录
2. 记录身高和体重
3. 记录当天训练，文本形式
4. 记录早中晚三餐，文本形式
5. 上传当天身材照片
6. 保存当天记录到本地
7. 使用 MiMo API 分析当天记录
8. 查看历史任意日期的记录

## 数据字段

- 日期
- 身高 cm
- 体重 kg
- 当天训练
- 早餐
- 午餐
- 晚餐
- 身材照片路径
- AI 分析结果

## 本地存储

第一版使用 App 本地私有存储：

- 文本记录保存在 SharedPreferences
- 照片复制到 App 私有目录 `body_photos`
- 每个日期一条记录

## AI 分析

用户在右上角设置里填写自己的 MiMo API Key。点击 AI 分析后，App 会把当天文本记录发送给 MiMo，返回：

- 今日概览
- 训练评价
- 饮食观察
- 明天建议
- 注意事项

注意：当前版本不会把照片内容发送给 AI，只会告诉 AI “是否上传了照片”。照片分析可以放到后续版本。

## 后续方向

- 体重趋势图
- 训练部位统计
- 饮食热量估算
- 周报/月报
- AI 对比不同日期的变化
- 支持多张照片和照片备注
